# saitkaplan.com

Source code of [saitkaplan.com](https://saitkaplan.com/), the personal website of Sait Kaplan. In English and Turkish.

The site is coming soon.

## Technology

React Router (framework mode, fully prerendered, `ssr: false`), React, TypeScript and Vite. The output is static HTML, CSS and JavaScript, published to GitHub Pages by GitHub Actions. Fonts (IBM Plex Sans, IBM Plex Mono) are served from the site itself.

## Running locally

Requires Node.js 22.22 or newer.

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```
